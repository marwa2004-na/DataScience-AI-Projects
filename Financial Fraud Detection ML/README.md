## Financial Fraud Detection

### Project Overview

An introductory AI course project exploring how machine learning can be used to identify potentially fraudulent financial transactions using a Random Forest classifier.

### Methodology

Synthetic transaction data was generated and used to train and evaluate a classification model. The dataset was split into training and testing sets, and model performance was assessed using accuracy, a confusion matrix, and a classification report.

### Technologies Used

Python

Pandas & NumPy: Data generation and manipulation.

Scikit-learn: Data preprocessing, model training, and evaluation.

### Key Learning Outcomes

Understanding supervised machine learning and classification.

Applying the Random Forest algorithm.

Preparing data and evaluating model performance.

Using a trained model to predict potential fraudulent transactions.
