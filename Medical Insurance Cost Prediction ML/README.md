## Medical Insurance Cost Prediction

### Project Overview

This project uses machine learning to predict medical insurance charges based on factors such as age, BMI, smoking status, gender, number of children, and region. It compares Linear Regression and Decision Tree Regression to identify the better-performing model.

### Techniques Used

Data cleaning and preprocessing

Exploratory Data Analysis (EDA)

Feature selection using ANOVA F-test

Linear Regression and Decision Tree Regression

Hyperparameter tuning using GridSearchCV

Model evaluation using R², MSE, and RMSE

Model deployment using Gradio

### Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, and Gradio.

### Results

The Decision Tree Regression model achieved an R² score of 0.9004, outperforming Linear Regression on the dataset.

### Dataset

Medical Insurance Cost Prediction – Kaggle
