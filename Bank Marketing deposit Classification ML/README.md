## Bank Marketing Deposit Classification

### Project Overview

This project uses machine learning to predict whether a bank customer will subscribe to a term deposit following a marketing campaign. The goal is to improve marketing efficiency by identifying potential customers.

### Techniques Used

Data cleaning and preprocessing

Exploratory Data Analysis (EDA) and visualization

Categorical encoding and feature scaling

Random Forest classification

Model evaluation using a confusion matrix, accuracy, precision, recall, and F1-score

Feature importance analysis

### Technologies

R, RStudio, Tidyverse, Caret, Random Forest, and ggplot2.

### Results

The Random Forest model achieved 85.04% accuracy on the test dataset. Call duration, campaign timing, account balance, and age were among the important predictors of customer subscriptions.

### Dataset

Bank Marketing Dataset – Kaggle
