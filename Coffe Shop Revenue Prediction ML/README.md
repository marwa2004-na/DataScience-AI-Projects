## Coffee Shop Daily Revenue Prediction 

### Project Overview

This project applies data analysis and machine learning techniques to analyze coffee shop operations and predict whether daily revenue will be low or high. It also identifies key factors influencing revenue to support data-driven business decisions.

### Techniques Used

Data cleaning and preprocessing

Exploratory Data Analysis (EDA) and visualization

Feature selection using Random Forest and Exhaustive Feature Selection

Linear Regression for revenue prediction

Logistic Regression for low/high revenue classification

Model evaluation using R², MSE, MAE, and accuracy

### Technologies

Python, Pandas, Matplotlib, Seaborn, Scikit-learn, and MLxtend.

Dataset

Coffee Shop Daily Revenue Prediction Dataset – Kaggle
