## Which Academic Assessments Cause Anxiety in UTAS Students?

### Project Overview

An academic research study investigating assessment-related anxiety among 101 students at the University of Technology and Applied Sciences (UTAS), Muscat, Oman.

### Objectives

Identify which assessment types cause the highest anxiety.

Analyze factors associated with academic anxiety.

Explore coping strategies and their relationship to student well-being.

### Methodology

Questionnaire data were collected using Microsoft Forms and analyzed using Python. Statistical methods included descriptive statistics, hypothesis testing, correlation analysis, and multiple linear regression.

### Key Findings

Examinations and presentations generated the highest anxiety levels, while assignments caused the least. Fear of mistakes, grading pressure, and performance concerns were important predictors of anxiety.

### Tools & Methods

Python: Statistical data analysis

Microsoft Forms: Data collection

Statistical Analysis: T-tests, correlation, and regression
